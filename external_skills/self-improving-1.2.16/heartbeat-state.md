# Template: `~/self-improving/heartbeat-state.md`

Copy these lines to `~/self-improving/heartbeat-state.md` on first setup (plain text / markdown):

```
last_run_utc:
last_reviewed_correction:
notes:
```

After each heartbeat run, fill `last_run_utc` (ISO 8601), optional `last_reviewed_correction`, and append to `notes`.
