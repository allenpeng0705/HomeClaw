# Learning mechanics

## Promotion (tentative → HOT)

- Same lesson **applied successfully 3×** within **7 days** → candidate for `memory.md`.
- Before locking in ambiguous rules, **ask** the user once to confirm.

## Demotion / archive

- Unused in **30 days** (HOT) → consider moving detail to `projects/` or `domains/`.
- Unused **90 days** → move to `archive/` with a one-line pointer in `index.md`.
- **Never** silently delete user-confirmed preferences.

## Conflicts

1. More specific scope wins: **project > domain > global**.
2. Same scope: **more recent** explicit instruction wins.
3. Still ambiguous: **ask** the user.

## False learning

- **Do not** infer rules from silence, missing replies, or “they didn’t complain.”
- One-off task wording (“for this file only”) must not become global without repetition or explicit “always.”
