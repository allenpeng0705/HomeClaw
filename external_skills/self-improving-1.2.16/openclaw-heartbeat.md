# OpenClaw heartbeat (upstream reference)

Upstream OpenClaw may ship a **`openclaw-heartbeat.md`** seed. In **HomeClaw**, use instead:

- **`homeclaw-heartbeat.md`** — cron + `HEARTBEAT.md` integration
- **`heartbeat-rules.md`** — what to do each run

This file exists so searches for “openclaw heartbeat” in migrated notes still resolve.
