# Self-reflection log

Append to `~/self-improving/reflections.md` (create if missing) or to `corrections.md` if you prefer a single log — stay consistent.

## Format

```
CONTEXT: [type of task]
REFLECTION: [what you noticed]
LESSON: [what to do differently]
```

## Example

```
CONTEXT: Building Flutter UI
REFLECTION: Spacing looked off; user had to ask for a second pass
LESSON: Check spacing against Material guidelines before presenting
```

## Promotion

Treat like other lessons: **3×** successful application → promote to HOT per `learning.md`.
